# TerraOS
TerraOS is a web OS inspired by the game **Terraria**. It is built in HTML + CSS + JavaScript.
![App Example](./assets/Screenshot%202026-10-28%20113310.png)

## Usage
The os can be accessed [here](https://gamerreaper09.github.io/webos/).
Apps can be opened by pressing the appicons. Windows can be moved by dragging the header and can be closed by pressing the red button.

## Features
* Movable windows
* Apps like notepad and music player
* Awsome design (If you like terrarias)
* Simple ui
